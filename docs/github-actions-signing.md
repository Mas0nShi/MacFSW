# GitHub Actions macOS Signing

This project builds a SwiftPM app bundle with an embedded Endpoint Security System Extension. The CI release workflow is:

1. Import a Developer ID Application certificate into a temporary keychain.
2. Restore the host app and System Extension provisioning profiles.
3. Run tests.
4. Build `MacFSW.app` with `Scripts/package-dev-app.sh`.
5. Sign the app and embedded `.systemextension` with hardened runtime and a secure timestamp.
6. Package the signed app into an installer-style DMG with an `/Applications` shortcut and drag-to-install guidance.
7. Submit the DMG to Apple's notary service, staple the ticket, and upload the DMG.

The workflow lives at `.github/workflows/macos-signed-release.yml` and runs on:

- manual `workflow_dispatch`
- pushed tags matching `v*`

## GitHub Secrets

Add these under `Settings` -> `Secrets and variables` -> `Actions` -> `Secrets`.

| Name | Required | Source | How to create/configure |
| --- | --- | --- | --- |
| `MACOS_CERTIFICATE_P12_BASE64` | Yes | Local Keychain Access export of `Developer ID Application: ...` including the private key | In Keychain Access, open `login` -> `My Certificates`, right-click the Developer ID Application certificate, export as `.p12`, set an export password, then run `base64 -i certificate.p12 | tr -d '\n' | pbcopy`. Paste the clipboard value into this secret. |
| `MACOS_CERTIFICATE_PASSWORD` | Yes | The password used when exporting the `.p12` file | Save the exact export password. |
| `MACOS_KEYCHAIN_PASSWORD` | Yes | Generated by you | Generate a strong random value. It only protects the temporary CI keychain. |
| `MACFSW_HOST_PROVISIONPROFILE_BASE64` | Yes | Apple Developer provisioning profile for `com.mas0n.MacFSW` | Download the macOS Developer ID provisioning profile for the host app App ID. It must include `com.apple.developer.system-extension.install`. Encode with `base64 -i Host.provisionprofile | tr -d '\n' | pbcopy`. |
| `MACFSW_EXTENSION_PROVISIONPROFILE_BASE64` | Yes | Apple Developer provisioning profile for `com.mas0n.MacFSW.EndpointExtension` | Download the macOS Developer ID provisioning profile for the System Extension App ID. It must include `com.apple.developer.endpoint-security.client`. Encode with `base64 -i Extension.provisionprofile | tr -d '\n' | pbcopy`. |
| `APPLE_ID` | Yes | Apple Account email used for notarization | Use the Apple Account that has access to the developer team. |
| `APPLE_APP_SPECIFIC_PASSWORD` | Yes | Apple Account app-specific password | Create it at `account.apple.com` -> `Sign-In and Security` -> `App-Specific Passwords`. Do not use your normal Apple Account password. |
| `APPLE_TEAM_ID` | Yes | Apple Developer Team ID | In Apple Developer, open `Membership details`. For this repository's checked-in signing config it should match `UYF535Y9QZ` unless you intentionally changed `Configuration/Signing.xcconfig` and the XPC signing policy. |

## GitHub Variables

Add this under `Settings` -> `Secrets and variables` -> `Actions` -> `Variables`.

| Name | Required | Source | How to create/configure |
| --- | --- | --- | --- |
| `MACOS_CODESIGN_IDENTITY` | No, but recommended | `security find-identity -v -p codesigning` on a Mac with the cert installed | Use the full common name, for example `Developer ID Application: Your Name (TEAMID)`. If omitted, the workflow uses the first imported `Developer ID Application` identity. |

## Apple Developer Requirements

The current bundle identifiers are defined in `Configuration/Signing.xcconfig`:

```text
DEVELOPMENT_TEAM = UYF535Y9QZ
MACFSW_HOST_BUNDLE_ID = com.mas0n.MacFSW
MACFSW_EXTENSION_BUNDLE_ID = com.mas0n.MacFSW.EndpointExtension
MACFSW_XPC_SERVICE_NAME = UYF535Y9QZ.com.mas0n.MacFSW.EndpointExtension.xpc
```

Before the workflow can pass, the Apple Developer account must have:

- a `Developer ID Application` certificate with a private key
- an App ID for `com.mas0n.MacFSW` with System Extension install capability
- an App ID for `com.mas0n.MacFSW.EndpointExtension` with Endpoint Security capability
- a Developer ID provisioning profile for each App ID
- access to Apple's notary service through the configured Apple Account

Endpoint Security is a restricted capability. The entitlement file in this repository is not enough by itself; the System Extension App ID and its provisioning profile must also contain `com.apple.developer.endpoint-security.client`.

## Local Export Commands

The recommended helper is:

```bash
Scripts/configure-github-signing-secrets.sh \
  --certificate-p12 ~/Desktop/macfsw-developer-id.p12 \
  --apple-id you@example.com
```

If the `Developer ID Application` identity is installed in your login keychain and you want the script to export a `.p12` first:

```bash
Scripts/configure-github-signing-secrets.sh \
  --export-login-keychain-p12 ~/Desktop/macfsw-developer-id.p12 \
  --apple-id you@example.com
```

The helper finds the two required provisioning profiles, writes the GitHub secrets with `gh secret set`, and prompts for sensitive passwords without echoing them.

Use these commands after exporting the certificate/profile files locally:

```bash
base64 -i macos-signing-cert.p12 | tr -d '\n' | pbcopy
base64 -i MacFSWHost.provisionprofile | tr -d '\n' | pbcopy
base64 -i MacFSWEndpointExtension.provisionprofile | tr -d '\n' | pbcopy
```

Check the local signing identity name:

```bash
security find-identity -v -p codesigning
```

## Running a Release

For a signed release, push a version tag:

```bash
git tag v0.1.7
git push origin v0.1.7
```

The workflow uploads the notarized DMG as a workflow artifact. For tag builds it also creates or updates a GitHub Release asset.

## DMG Layout

Release DMGs are generated by:

```bash
Scripts/create-release-dmg.sh .build/bundles/MacFSW.app .build/release-artifacts/MacFSW-0.1.7.dmg
```

The DMG contains:

- `MacFSW.app`
- an `Applications` symlink pointing to `/Applications`
- a Finder background that instructs users to drag `MacFSW.app` into `Applications`

This installation step is required because macOS rejects normal System Extension activation when the host app is launched directly from the mounted DMG.
